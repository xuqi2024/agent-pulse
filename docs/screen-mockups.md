# 屏幕草图

屏幕：**320 × 240** 像素（横屏），自绘 5x7 ASCII 字模（最多 53 列 × 30 行）。

## 1. IDLE — 空闲

```
+--------------------------------------+
|  *  agent-pulse  *           #0E1B2C |   <- 深蓝底，绿色字
+--------------------------------------+
|                                      |
|                                      |
|              ●                       |   <- 呼吸点（动画）
|                                      |
|             OK                       |   <- 大字 28pt 绿
|           standby                    |   <- 副标题 14pt 灰
|                                      |
|                                      |
|        waiting for agent ...         |   <- 底部 11pt 灰
+--------------------------------------+
```

颜色：背景 `#0E1B2C`，强调色 `#6FE3A1`（绿），副色 `#788291`（灰）。

## 2. PROCESSING — 处理中

```
+--------------------------------------+
|  >>>  AGENT RUNNING          #1B1F2A |   <- 深灰底，黄色字
+--------------------------------------+
|                                ◯     |   <- 旋转 spinner（动画）
|                                      |
|  tool:  Bash                  #FFD166|
|                                      |
|  pytest tests/ -q                    |   <- 当前命令
|  [####################--------] 68%  |   <- 进度条
|                                      |
|  0:03  |  model: claude-sonnet-4.5   |   <- 状态条
+--------------------------------------+
```

颜色：背景 `#1B1F2A`，强调色 `#FFD166`（黄）。

进度条可选（progress 字段为 255 时不显示）。

## 3. ERROR — 错误 / 权限请求

```
+--------------------------------------+
|  !!!  AGENT BLOCKED          #2A0E12 |   <- 深红底，红色字
+--------------------------------------+
|                                      |
|                                      |
|          PERMISSION                  |   <- 大字 22pt 红
|          REQUIRED                    |
|                                      |
|  Bash wants to run:                  |   <- 描述
|  rm -rf ./build                      |
|                                      |
|                                      |
|  [press BOOT to clear]               |   <- 操作提示
+--------------------------------------+
```

颜色：背景 `#2A0E12`，强调色 `#FF6B6B`（红）。

## 4. NO LINK — 看门狗超时

```
+--------------------------------------+
|  !!  NO LINK                #0E1B2C  |   <- 蓝底，红色字
+--------------------------------------+
|                                      |
|          CONNECTION                  |   <- 红
|          LOST                        |
|                                      |
|        check USB cable               |   <- 灰
|                                      |
|        [press BOOT to retry]         |   <- 灰
+--------------------------------------+
```

## 5. BOOT — 启动

```
+--------------------------------------+
|  *  agent-pulse  *           #0E1B2C |   <- 蓝底，青色字
+--------------------------------------+
|                                      |
|                                      |
|         booting ...                  |   <- 青色
|                                      |
|                                      |
+--------------------------------------+
```

只在固件启动后 0.5s 内出现，之后自动进 IDLE。

## 动画

- IDLE 屏：呼吸点（圆点大小 6→10px 周期性变化，2s 周期，sin 曲线）
- PROCESSING 屏：右上角 8 段虚线 spinner，每帧旋转 12°（≈ 1.5s/圈）
- ERROR / NO LINK：静态，无动画
- BOOT：静态

## 字体

- 5×7 ASCII 字模
- 标题 11pt（1x scale），状态字 22-28pt（2-3x scale），正文 11-13pt
- 全部内嵌 `firmware/main/font_5x7.h`，无外部依赖
